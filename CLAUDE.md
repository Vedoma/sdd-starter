# CLAUDE.md

Project memory for Claude Code. Its one job: make `constitution.md` and `AGENTS.md`
genuinely always-loaded. Before this file existed the constitution was in an agent's
context only inside the nine `/`-commands — yet most work (implementation turns,
follow-up questions, ad-hoc edits) happens outside a command, exactly where the rules
were absent.

The two files below are **imported, not summarized**: Claude Code inlines their full
content via `@`. The binding principles, the lifecycle, the non-negotiables, the
provenance rules, the human checkpoints, and what `spec-lint` does and does not enforce
all live there. Do not restate any of it here — edit the source instead, so there is one
copy to keep current.
