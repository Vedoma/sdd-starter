# /review - Pull request review

Load and obey [`constitution.md`](../../constitution.md) first (binding principles),
then follow the canonical prompt at [`prompts/review.md`](../../prompts/review.md). The
prompt file is the source of truth for this - do not duplicate its content here.

Usage: `/review [PR]`. Review is not a numbered phase; it applies to every PR.

Verify each finding before you report it, and say what you did not check.
